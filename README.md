# Universal Video Downloader

A Python-based video downloader using `yt-dlp` to retrieve video information and download supported media.

## Features

- Download videos from supported websites
- Uses `yt-dlp` for video extraction
- Command-line based Python implementation
- Simple and lightweight project

## Technologies Used

- Python
- yt-dlp

## Requirements

- Python 3.10 or newer recommended
- pip

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/VishalKumar7084/universal-video-downloader.git
   ```

2. Open the project folder:

   ```bash
   cd universal-video-downloader
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

## Usage

Run the Python script:

```bash
python best.py
```

Follow the prompts displayed by the program.

## Troubleshooting

- Update yt-dlp if a supported website changes its video extraction process.
- Check your internet connection if video information takes a long time to load.
- Some websites may require additional authentication or may restrict downloads.

## Disclaimer

Use this tool only for content you own or have permission to download. Respect copyright laws and the terms of service of the websites you use.
